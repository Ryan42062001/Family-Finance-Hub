## Manager finding FFH-013-M02 — HIGH — equal-compensation owner-only excess must remain owner-local
Status: OPEN / BLOCKING.

Manager review of PR #23 found a new boundary not covered by the remediation suite.

Accepted FFH-009 policy explicitly states that when spouse compensation is equal, neither spouse is the lower-compensation spouse for a spousal enhancement. Each spouse independently uses:

`max(0, min(L_i, C_i) - Y_i)`

No MFJ shared compensation group is created merely because one equal-compensation spouse exceeds that spouse's own ceiling.

Concrete reproduction:
- spouse A compensation: `$10,000`;
- spouse B compensation: `$10,000`;
- both under age 50, individual IRA limit `$7,500` each;
- A authoritative IRA YTD: `$8,000`;
- B authoritative IRA YTD: `$0`.

Required result:
- A additional IRA room: `$0` plus owner-excess warning;
- B additional IRA room: `$7,500`;
- no shared MFJ group is created solely because A has an owner-only excess;
- reversing spouse/account/input order does not change the material result.

PR #23 currently detects `ownerExcesses=[A]`, sets shared remaining to zero, and creates the shared group for both because an owner excess exists. That incorrectly reduces B from `$7,500` valid independent room to `$0`.

Remediation must distinguish:
- unequal-compensation cases where the accepted spousal/shared feasible set applies and A04 correctly fails the affected shared group closed; from
- equal-compensation cases where no spousal enhancement/shared group applies and an owner-only excess remains owner-local unless a separate joint ceiling is actually violated.
