## Objective
Implement FFH-D006 owner-conditional IRA maxima plus one shared MFJ compensation ledger, replacing the current deterministic sorted-owner compensation allocation without changing Roth eligibility or Traditional IRA deductibility rules.

The accepted regulatory/policy problem is that scarce MFJ compensation is a shared legal constraint, not a permanent owner-ID-first statutory allocation. Core must represent owner-conditional maxima without presenting a deterministic engineering split as owner-specific legal capacity.

- owner conditional maxima remain non-additive without the shared ledger;
- shared MFJ compensation cannot be exceeded in aggregate;

## Manager finding FFH-013-M01 — recurring equal-fulfillment cent reconciliation
Severity: HIGH
Status: WORKER REMEDIATED / PENDING MANAGER VERIFICATION

The submitted annual legal-capacity ledger was bounded correctly, but Build's routable-capacity prepass and its actual equal-fulfillment routing used different allocation/rounding paths.

Concrete reachable example from the submitted code:
- shared MFJ IRA compensation remaining: `$10,000.01`;
- each spouse owner-conditional remaining room: `$7,500.00`;
- the routable-capacity prepass consumed destinations sequentially and derived `$625.00 + $208.33 = $833.33` monthly capacity;
- Build therefore authorized `$833.33` monthly retirement routing;
- the actual tied-spouse router requested `roundMoney($833.33 * 12) = $9,999.96` annually and equal-fulfillment split `$4,999.98 / $4,999.98`;
- each account route rounded to `$416.67` monthly;
- account-level monthly routes therefore summed to `$833.34`, one cent above the Build retirement request;
- `retirementToRoute` clamped to zero after subtraction, so the mismatch was not rejected.

The bounded remediation makes both the Build capacity prepass and actual equal-owner routing reconcile the same recurring monthly-cent request. For the same `$10,000.01` shared pool, the authoritative `$833.33` recurring request is `83,333` cents and routes deterministically as `$416.67 + $416.66 = $833.33`. The corresponding annual legal-ledger consumption is `$5,000.04 + $4,999.92 = $9,999.96`, leaving `$0.05` shared room. Stable identity is used only for the unavoidable odd recurring cent. No tolerance/epsilon was introduced, the routing invariant was not weakened, and legal capacity was not reverted to sorted-owner allocation.

Direct Build-level regression coverage proves exact monthly reconciliation, annual conservation, invariant preservation, and account-order invariance for this adversarial boundary.
