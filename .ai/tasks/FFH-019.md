## Objective

Simplify how the Family Finance Hub AI workforce is operated without weakening financial correctness, specialist separation, task/checkpoint authority, or audit gates.

Family Finance Hub is the personal-finance website/application. This task does not apply to The War Room, The Chip Winner, or the ECOG church website.

## Changes implemented

- added `.ai/shared/WORKFLOW_V3.md` as a focused operating overlay on top of Workflow V2;
- reorganized the user-facing team into five departments while preserving all ten specialist role boundaries;
- made `ROLE = DURABLE`, `CHAT = DISPOSABLE`, `TASK = UNIT OF WORK`, `REPOSITORY = MEMORY` explicit;
- changed the default worker-chat model to one fresh chat per meaningful task, with small same-task remediation allowed to remain in the same chat;
- established Manager chat rollover at phase/milestone boundaries or earlier when context size degrades performance/state accuracy;
- added minimum-sufficient-context startup guidance for replacement chats;
- added formal Manager execution-mode classification: `STANDARD_CHAT`, `WORK_MODE_PREFERRED`, `WORK_MODE_HIGH_VALUE`;
- required a normal-chat fallback for Work-preferred/high-value tasks whenever the underlying work can still proceed without Work mode;
- preserved the existing 2–4 active-chat target and event-driven Manager model;
- preserved existing Troubleshooting & Build escalation semantics;
- preserved specialist Engineering, Policy, Research, and dual-Audit authority rather than collapsing roles for cosmetic simplicity;
- updated `.ai/roles/README.md` and `.ai/roles/manager.md` to bootstrap replacement chats under V3.
