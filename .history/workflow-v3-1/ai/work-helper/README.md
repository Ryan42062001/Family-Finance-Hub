# Work Helper / Super Troubleshooter

This folder is the dedicated repository memory for Family Finance Hub's on-demand technical recovery role.

Canonical role charter: `.ai/roles/work-helper.md`
Canonical operating supplement: `.ai/shared/WORK_HELPER_OVERLAY.md`

Use this folder for:
- `HANDOFF.md` — current continuity/status pointer;
- `PLAYBOOK.md` — durable troubleshooting method;
- task-specific diagnostic notes/evidence when a recovery assignment needs a persistent artifact.

Work Helper is independent of the permanent five-department presentation. It may be activated temporarily as a dedicated recovery chat when Manager determines that fresh-context, cross-cutting troubleshooting is the fastest safe path.

Work Helper does not own financial policy, regulatory interpretation, audit verdicts, roadmap authority, acceptance, or merge authority.
